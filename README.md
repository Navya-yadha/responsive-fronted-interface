A modern, responsive frontend web application built using HTML5, CSS3, and JavaScript. This project demonstrates the implementation of a mobile-first design approach, responsive layouts, and basic interactivity without using any frontend frameworks.

🚀 Features
Responsive Navigation Bar
Mobile Menu Toggle
Hero Section
Feature Cards Layout
About Section
Footer Section
CSS Grid & Flexbox Layouts
Mobile-First Responsive Design
JavaScript Interactivity
Clean and Modern User Interface

HTML5
